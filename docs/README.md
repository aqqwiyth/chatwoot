## 名称边界

- **企业微信群**属于统一群聊渠道，代码标识为 `group_messaging`，当前启用的 provider 是 `wecom`。
- **微信客服**是面向客服账号的独立渠道，代码标识为 `wecom_customer_service`。
- 两者使用不同的回调地址、数据模型和消息同步流程，不要混用配置项或 Webhook 地址。

## 推荐验证顺序

1. 按目标渠道完成收件箱配置。
2. 先验证回调签名、渠道标识和异步任务是否正常入队。
3. 确认 Chatwoot 联系人、会话和消息创建成功，再验证机器人 Webhook 或管理员出站回复。
4. 发布前执行对应文档中的数据库迁移、测试和部署检查。

## 文档维护约定

- 产品名、渠道名和代码标识保持一致，新增渠道时同步更新本索引。
- 仅在功能行为或运行方式变化时更新详细文档，避免把临时调试命令写入发布 Runbook。
- 示例中的域名、账号和密钥均使用占位符，不要提交真实凭据。
